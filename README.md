# 🌙 Croissant Rouge – Charitable Association Management

Desktop application built with **VB.NET and Windows Forms (.NET 8)** to help the leaders of a charitable association manage beneficiaries, donors, members and finances.

## Features
- Role-based entry: needy person or association member (with authentication)
- Records of needy people, responsible persons, members and donors: add, show list, search, edit, delete
- Donation tracking (cash or in kind)
- Accounting management: total of collected amounts from actions and donations

## Run
1. Open `associoation.sln` in Visual Studio 2022 (with the .NET desktop workload).
2. Build and run (F5).
